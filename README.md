# Kuis & Kartu Parasitologi Veteriner
Dibuat oleh **Yosa**

Website statis (HTML/CSS/JS, tanpa build). Fitur: kuis tebak parasit dengan timer 10/15/20 detik atau tanpa waktu, dan flashcard (balik otomatis opsional).

## Cara publikasi di GitHub Pages
1. Buat repository baru di GitHub, lalu upload SEMUA isi folder ini (index.html, style.css, app.js, data.js, folder assets, .nojekyll).
2. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. Tunggu 1-2 menit, website aktif di https://USERNAME.github.io/NAMA-REPO/
